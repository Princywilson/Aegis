## Formatting Before Submission

- Replace all `[Name]`, `[Institution]`, `[University]`, registration or submission fields.
- Use Times New Roman 12 pt for body text and 1.5 line spacing.
- Use single spacing for long tables and references.
- Use the prescribed A4 and margin dimensions.
- Recalculate the table of contents and Roman/Arabic page numbering after adding screenshots.
- Render Mermaid diagrams or replace them with appropriately labeled diagrams.
- Add only genuine, sanitized browser screenshots.
- Keep the first chapter through final chapter within the 60-page limit.
- Add signed bonafide, external examiner, guide and project in-charge certificates in the final PDF.
- Do not include real `.env` secrets or credentials.
