## C.3 Screenshot Requirements

- Record date and account role.
- Use synthetic names and email addresses.
- Remove browser address data when it contains credentials or private environment details.
- Do not include passwords, cookies, CSRF tokens or session IDs.
- Do not include genuine proprietary or personal content.
- Use the same resolution and browser theme for a cohesive report.
- Insert each screenshot immediately after first textual reference.
- Number as `Figure 4.1`, `Figure 4.2`, or another chapter-appropriate number.
- Add a 1–2 line caption below the screenshot.

## C.4 Evidence Retention

Retain source screenshots outside the project repository if they contain operational environment information. Store only approved, sanitized copies in the report package. Confirm that the institution accepts digital attachments and screenshots before fixing the final number of report pages.
